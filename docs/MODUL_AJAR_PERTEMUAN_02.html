A. Identitas & Tujuan Pembelajaran

Setelah mengikuti pembelajaran pada modul ini, siswa diharapkan mampu:

  • Memahami konsep arsitektur Client-Server dan siklus Request-Response.
  • Menginstal serta mengonfigurasi dependensi pendukung (dotenv, cors, dan nodemon).
  • Menyimpan variabel lingkungan port pada file .env secara terpisah dan aman.
  • Menulis kode web server HTTP pertama menggunakan framework Express.js pada src/server.js.
  • Membuat endpoint routing GET dengan respon standar JSON.
  • Menangani rute yang tidak terdaftar melalui error handler 404 Not Found.
  • Menguji endpoint API menggunakan browser dan aplikasi Postman / Thunder Client.

C. Langkah Kerja Praktikum (Step-by-Step)

Langkah 1: Membuka Folder Backend di Terminal

Pastikan terminal VS Code aktif dan mengarah ke dalam folder backend:

cd backend

Langkah 2: Menginstal Paket Dependensi

Jalankan perintah berikut untuk mengunduh pustaka pembantu:

npm install dotenv cors
npm install -D nodemon
💡 Penjelasan Paket:
• dotenv: Membaca file konfigurasi .env.
• cors: Membuka izin agar backend dapat diakses oleh frontend Next.js.
• nodemon: Me-restart server secara otomatis setiap kali file disimpan.

Langkah 3: Konfigurasi Script di package.json

Buka file backend/package.json dan tambahkan script dev dan start:

{
  "name": "backend",
  "version": "1.0.0",
  "main": "src/server.js",
  "scripts": {
    "start": "node src/server.js",
    "dev": "nodemon src/server.js"
  },
  "dependencies": {
    "cors": "^2.8.6",
    "dotenv": "^17.4.2",
    "express": "^5.2.1"
  },
  "devDependencies": {
    "nodemon": "^3.1.14"
  }
}

Langkah 4: Membuat File Konfigurasi .env

Buat file baru bernama .env di dalam folder backend/ (sejajar dengan package.json):

# Konfigurasi Server
PORT=5000
NODE_ENV=development

Langkah 5: Menulis Kode Server di src/server.js

Buka file backend/src/server.js lalu ketikkan kode lengkap berikut:

// 1. IMPORT MODUL
const express = require('express');
const dotenv = require('dotenv');
const cors = require('cors');

// 2. LOAD KONFIGURASI .ENV
dotenv.config();

// 3. INISIALISASI EXPRESS & PORT
const app = express();
const PORT = process.env.PORT || 5000;

// 4. MIDDLEWARE DASAR
app.use(cors()); 
app.use(express.json()); 
app.use(express.urlencoded({ extended: true })); 

// 5. ENDPOINT DASAR
// Route Utama (Root)
app.get('/', (req, res) => {
    res.status(200).json({
        success: true,
        message: 'Selamat datang di API Portofolio Dinamis!',
        version: '1.0.0'
    });
});

// Route Cek Status Server
app.get('/api/status', (req, res) => {
    res.status(200).json({
        success: true,
        message: 'Server dalam keadaan sehat dan aktif.',
        timestamp: new Date().toISOString()
    });
});

// 6. PENANGANAN 404 NOT FOUND
app.use((req, res) => {
    res.status(404).json({
        success: false,
        message: 'Endpoint tidak ditemukan!'
    });
});

// 7. MENJALANKAN SERVER
app.listen(PORT, () => {
    console.log(`========================================`);
    console.log(`🚀 Server berjalan di: http://localhost:${PORT}`);
    console.log(`📡 Mode: ${process.env.NODE_ENV || 'development'}`);
    console.log(`========================================`);
});

D. Tabel Bedah Kode (Penjelasan Teknis)

Sintaks Kode Fungsi & Makna Teknis
const app = express() Membuat instance utama aplikasi Express sebagai penampung routing dan middleware.
dotenv.config() Membaca file .env dan memasukkan nilainya ke process.env.
app.use(cors()) Middleware keamanan yang mengizinkan request lintas domain (CORS).
app.use(express.json()) Body-parser bawaan Express untuk mengenali data bertipe JSON dari request klien.
app.get(path, handler) Mendaftarkan rute dengan method HTTP GET.
res.status(200).json(...) Mengirim status code 200 (Success) beserta data berformat JSON ke klien.
app.use((req, res) => {...}) Handler fallback untuk menangani request ke endpoint yang tidak terdaftar (404).
app.listen(PORT, callback) Menginstruksikan server untuk mulai mendengarkan koneksi pada nomor port tertentu.

E. Pengujian Endpoint API

Jalankan server pengembangan di terminal:

npm run dev

Buka Web Browser atau Thunder Client / Postman, lalu akses URL berikut:

  • http://localhost:5000/ $\rightarrow$ Status 200 OK (Pesan Sambutan).
  • http://localhost:5000/api/status $\rightarrow$ Status 200 OK (Jam Server).
  • http://localhost:5000/api/random $\rightarrow$ Status 404 (Endpoint tidak ditemukan).

G. Panduan Troubleshooting

Pesan Error Penyebab & Solusi
EADDRINUSE :::5000 Port 5000 sedang terpakai. Matikan server lama dengan Ctrl + C atau ubah port di .env menjadi 5001.
Cannot find module 'express' Folder kerja salah. Pastikan berada di folder backend lalu jalankan npm install.
Script disabled on PowerShell Gunakan Command Prompt (cmd) atau jalankan dengan npx nodemon src/server.js.
