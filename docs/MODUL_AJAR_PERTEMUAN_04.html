A. Tujuan Pembelajaran Khusus (TP)

  • Memahami konsep Arsitektur MVC (Model-View-Controller) dalam pengembangan Backend API.
  • Menginstal pustaka mysql2 sebagai perantara (driver) ke database MySQL.
  • Memperbarui konfigurasi kredensial koneksi di dalam file .env.
  • Membuat file config/db.js yang mengimplementasikan Connection Pool.
  • Menguji coba agar server dan database saling terhubung dengan sukses (✅).

B. Landasan Teori Singkat

1. Apa itu Arsitektur MVC?

MVC (Model-View-Controller) adalah pola penataan folder dan logika aplikasi. Model khusus mengatur database, View mengatur tampilan halaman, dan Controller menjadi otak pengatur antara Model dan View.

2. Connection Pool vs Koneksi Biasa

Daripada membuat koneksi baru dari nol setiap ada permintaan klien, Connection Pool menyediakan sekumpulan "koneksi siap pakai". Saat tugas selesai, koneksi dikembalikan ke dalam kolam (*pool*). Hasilnya, respon server lebih cepat dan efisien!

C. Langkah Kerja Praktikum (Step-by-Step)

Langkah 1: Instalasi Paket mysql2

Buka terminal di dalam folder backend, jalankan perintah:

npm install mysql2
💡 Penjelasan: Modul mysql2 lebih disarankan daripada modul lawas mysql karena mendukung fitur modern seperti Promises (async/await).

Langkah 2: Menambahkan Konfigurasi di File .env

Buka file backend/src/.env, tambahkan bagian Database MySQL:

# Konfigurasi Server
PORT=5000
NODE_ENV=development

# Konfigurasi Database MySQL
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=db_portofolio

(Catatan: Jika MySQL di komputer Anda memiliki password, silakan diisi pada baris DB_PASSWORD)

Langkah 3: Membuat File Koneksi Database db.js

Buat file baru di direktori backend/src/config/db.js dan isi kode berikut:

// 1. Import library mysql2 dan dotenv
const mysql = require('mysql2');
require('dotenv').config();

// 2. Membuat connection pool
const pool = mysql.createPool({
    host: process.env.DB_HOST,
    user: process.env.DB_USER,
    password: process.env.DB_PASSWORD,
    database: process.env.DB_NAME,
    waitForConnections: true,
    connectionLimit: 10,
    queueLimit: 0
});

// 3. Menggunakan promise wrapper (async/await support)
const db = pool.promise();

// 4. Mengetes koneksi ke database saat file ini dipanggil
pool.getConnection((err, connection) => {
    if (err) {
        console.error('❌ Kesalahan Koneksi Database:', err.message);
    } else {
        console.log('✅ Berhasil terhubung ke Database MySQL (db_portofolio)');
        connection.release();
    }
});

// 5. Export module agar bisa digunakan di controller/model
module.exports = db;

Langkah 4: Memanggil Koneksi di server.js

Buka backend/src/server.js, dan tambahkan pemanggilan database tepat di bawah dotenv.config();.

// 2. Load file konfigurasi .env
dotenv.config();

// Tambahkan baris ini untuk memanggil koneksi database
const db = require('./config/db');

// 3. Inisialisasi aplikasi Express
const app = express();
// ... dst ...

Langkah 5: Pengujian (Testing)

Pastikan modul MySQL di XAMPP hidup. Jalankan server dengan perintah:

npm run dev

Cek Terminal: Jika terhubung, akan muncul tulisan ✅ Berhasil terhubung ke Database MySQL (db_portofolio).
